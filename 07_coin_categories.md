# PowPowPow Coin Categories

## Category Structure

```
chains/
├── useful-pow/        # Mining does useful work
│   ├── QUBIC/         # Brain-inspired AI compute
│   ├── PRL/           # Matrix multiplication mining
│   ├── TSC/           # LLM inference mining
│   ├── GNK/           # Decentralized AI inference
│   └── NOCK/          # ZK proof generation
│
├── compute-market/    # Provider hardware markets
│   ├── AKT/           # GPU/CPU capacity marketplace
│   └── GNK/           # AI inference marketplace
│
├── zk-proving/        # Proof generation markets
│   ├── LA/            # ZK proof marketplace
│   └── NOCK/          # ZK-PoW
│
├── tee-compute/       # Trusted execution
│   └── PHA/           # Confidential compute (TEE)
│
├── intelligence/      # AI/intelligence economies
│   └── TAO/           # Subnet-based AI markets
│
├── privacy/           # Privacy & monetary security
│   ├── XMR/           # Ring signatures
│   └── NPT/           # ZK-STARK privacy
│
├── post-quantum/      # Quantum-resistant
│   ├── QRL/           # XMSS signatures
│   └── QUAN/          # ML-DSA signatures
│
├── monetary/          # Monetary experiments
│   └── ZEPH/          # Stablecoin + reserve
│
├── high-throughput/   # Fast PoW
│   └── KAS/           # 10 blocks/sec
│
├── sharded/           # Parallel architectures
│   └── ALPH/          # Blockflow sharding
│
├── utxo-defi/         # Programmable UTXO
│   └── ERG/           # Autolykos + DeFi
│
└── mature-pow/        # Control group
    ├── XMR/           # RandomX benchmark
    └── ERG/           # Mature GPU PoW
```

## Category Metadata

| Category | Scarce Resource | Key Question |
|----------|-----------------|--------------|
| useful-pow | Compute/Proof | Is the work actually useful? |
| compute-market | Hardware capacity | What's the market price for compute? |
| zk-proving | Proof generation | What does verification cost? |
| tee-compute | Attested compute | Can execution be trusted? |
| intelligence | Machine intelligence | Is AI inference being paid for? |
| privacy | Privacy | What's privacy worth? |
| post-quantum | Quantum resilience | What's PQ security worth? |
| monetary | Monetary stability | Is the stablecoin mechanism working? |
| high-throughput | Block throughput | Can scale without decentralizing? |
| sharded | Shard capacity | Does sharding actually scale? |
| utxo-defi | Programmable UTXO | Can UTXO compete with accounts? |
| mature-pow | Consensus security | How does mature PoW compare? |

## Cross-Category Comparisons

### Useful Compute Stack
```
AKT (capacity) → GNK (inference) → PRL (mining) → TSC (verified inference)
```

### Privacy Stack
```
XMR (privacy) → QUAN (post-quantum) → NPT (ZK-STARK) → ZEPH (monetary)
```

### Proof Stack
```
NOCK (ZK-PoW) → LA (proof marketplace) → TAO (intelligence proofs)
```
