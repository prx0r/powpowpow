# qubicex — Qubic mining explainer content

Plain-English explainers of what Qubic mining actually is, built from
measured data (ANN explorer API, warehouse tables). Audience: smart
non-experts. Rule: every claim cites a checkable source.

## Pieces

- `01-what-solutions-mean.md` — what a mining solution is (trained net +
  genome hash + nonce/seed), scoring, verification pass/fail.
- `02-phases-plain-english.md` — Phase 1/2/3 with zero jargon; the
  school-vs-breeding analogy; the four hard questions answered.
- `03-what-the-explorer-reveals.md` — what the operation looks like from
  outside: weekly loop, versioned tasks, reputation leaderboard.
- `04-scorecard.md` — honest ledger: infrastructure ✅, science program ✅,
  finished AGI ❌, revenue ❌. Updated as evidence changes.
- `05-aigarth-claims.md` — what the founder actually said, quoted verbatim
  with sources. No hype laundering in either direction.
