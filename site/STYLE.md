# PowPowPow Site Style Guide

> **Keep this forever — it IS the PowPowPow style.**

## Palette
- Black (#111) for borders, text, rails, active elements
- White (#fff) for backgrounds, data cells
- Grey (#f0f0f0, #f5f5f5) for panel backgrounds
- Grey (#777, #555) for dim text, labels, timestamps
- No color except meaning. No red, no green, no blue.

## Typography
- Arial/sans-serif body, 13px, 1.5 line-height
- Monospace (ui-monospace, Menlo) for ALL numbers
- Headers: 900 weight, uppercase, letter-spacing 1px
- Data tables: 11.5px, tabular-nums

## Borders
- 2px solid #111 on everything: panels, cards, tables, inputs, canvases
- No rounded corners. Ever.
- No shadows. Ever.

## Charts
- Canvas, 100% width, 150px height
- Black stroke, 3px, no fill except bar charts (black positive, grey negative)
- Black text for labels, monospace font
- No gridlines, no axes labels except the last value

## Panels
- Rail: 48px wide, #111 background, 9px bold labels
- Sidebar: 240px, #f0f0f0, key-value pairs
- Main: scrollable, max 940px
- Bottom: 150px, #f0f0f0, monospace log
- Chat: 310px right panel, resizable

## Data presentation
- Dense tables over cards when possible
- Grid of stat boxes for hero numbers
- Every number carries its unit and source
- No opinions. No bullish/bearish. Just what the data says.
